# 文体边界与反例

词句和篇章规则必须先看文本用途。同一表达在一种文体可能空泛，在另一种文体可能承担证据、导航、礼貌或节奏功能。示例由本项目自拟，用于说明边界，不作固定替换模板。关于跨文体差异的研究线索见 [sources.md](sources.md) 中 S-PNAS、S-DIVERSITY 和 S-NEWS。

| 文体与判断重点 | 值得改的情况 | 应保留的情况与误改风险 |
| --- | --- | --- |
| 技术说明：可操作性优先 | “通过一系列操作实现导出”且下文只有一个按钮时，可直接写“点击「导出」”。 | “先备份，再升级”是有顺序的步骤；专业术语、参数、命令、标题和表格数据不能为口语化而改动。 |
| 新闻或事实性说明：来源、时间和确定度优先 | “这一成果具有划时代意义”在报道中没有来源或具体事实时，不用它代替已给出的事实。 | “据市气象台预计，周五可能降雨”中的来源、预测和“可能”不可删成“周五降雨”。 |
| 商务说明：承诺与限制优先 | “赋能业务实现价值跃升”若只是复述“每月自动生成报表”，可说明具体功能。 | “预计十月交付，具体时间以验收为准”中的条件不可删成“十月交付”。标题已说明统计对象时，简洁的列表标签也不必扩写成完整句。 |
| 评论：论证和作者立场优先 | 空泛的“值得深思”若不增加判断，可删；已有理由应直接呈现。 | “我反对这项安排，因为它把成本转给小商户”不能为显得客观而改成中立介绍。 |
| 个人随笔：个人声音和叙事节奏优先 | 连续几段相同的无信息套语可局部删减；没有强调或节奏作用的重复主语，可只去掉重复处。 | 犹豫、口头词、反复或长句可能是作者有意的节奏；不能凭“正式程度”统一改写，更不能补造个人经历。叙事中的概括称呼、省略和问答穿插只要可由上下文理解，就不按分类严密性重新命名或补全；只有造成具体误解时才编辑。可理解的非标准口头表达、否定方式和时间体貌也属于个人声音；不能以规范语法为由换词，尤其不能顺带改变否定词或完成、持续等表达。明确的助词误用和无节奏作用的重复主语仍按词句规则局部处理。 |
| 口播与对话：听觉理解和互动功能优先 | 无实际作用的长串预告可压短，让听众更快听到重点。 | “先说结论”“我们回到刚才的问题”可能帮助听众定位；称呼、停顿和自然重复不能按书面稿规则一律删掉。 |

当文体不明时，沿用原文已有语域，只处理跨文体也明确成立的问题，例如无用重复或指代不清。不能根据词语、标点或排版推断“它像 AI 写的”，也不能把所有文体改成统一口语风。正文涉及高风险事实或作者立场时，以[编辑契约](editing-guide.md)的保真约束为准。
